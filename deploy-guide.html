02The upload — 4 minutes
  1. Go to github.com/alihoury003/Anastomosis.MD and make sure the branch selector (top-left of the file list) says main.
  2. Click Add file → Upload files.
  3. Drag all 13 files from the list above into the drop zone. GitHub will show them as modified/new — that's exactly right. Upload them flat, at the repo root, not into folders.
  4. Commit message: Unified favicons + OG cards — then click Commit changes.
  5. Wait ~2 minutes. Appwrite picks up the push and redeploys automatically. Done — that's the whole deploy.
