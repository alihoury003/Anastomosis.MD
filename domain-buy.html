03 · Connect the website

Recommended first route: keep the chosen registrar's DNS and use an apex ALIAS for anastomosismd.com. This avoids changing the whole domain's nameservers. Both Namecheap BasicDNS and Porkbun DNS support ALIAS; Appwrite supports apex connections through ALIAS/ANAME or CNAME flattening. Copy the exact target and any CAA details from your own Appwrite console—do not guess them. Namecheap instructions · Porkbun instructions · Appwrite instructions.
  1. In Appwrite: open the existing project → Sites → the existing site (the one currently served at medchanic-md.appwrite.network) → Domains → Add domain. Enter anastomosismd.com and choose Active deployment. If prompted, follow the external-domain ownership step in the same organization.
  2. Choose the CNAME flattening / keep nameservers route if shown. Note the hostname target and any CAA record Appwrite requires. Share that screen with the agent, omitting account or payment details, before changing DNS.
  3. At the selected registrar: in Namecheap, go to Domain List → Manage → Advanced DNS; for the ALIAS use host @. In Porkbun, go to Domain Management → Details → Edit DNS Records; choose ALIAS and leave its root host field blank. In either case use Appwrite's exact hostname target and add the exact CAA record if required by the console. These instructions assume you kept the registrar's DNS service.
  4. Inspect any existing @ A, AAAA, CNAME, ALIAS or URL-redirect records for conflicts. For a fresh parked domain, replace only the conflicting parking record after checking it. Do not delete unrelated MX, TXT or CAA records; they can be needed for email and verification.
  5. Back in Appwrite, verify the domain and wait for DNS and the HTTPS certificate to become ready. Appwrite says DNS changes may take up to 48 hours. Keep the old Appwrite address active throughout.
