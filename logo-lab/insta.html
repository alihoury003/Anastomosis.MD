ANASTOMOSIS.MD · IN THE WILD · AVATAR-FIRST · 23 OCT 2026

Born in the profile view.

Per the new rule: every mark is now created inside the Instagram profile view — because that is where it will live or die. The rendered 3D style is dropped. What remains: flat marks, one subject, centered, built for the circle.

The research, applied.

  • The circle crop is a filter, not a container — the mark lives in the central ~65% with breathing room; corners are dead territory.
  • At 110 px, detail dies — one subject, strong shapes, high contrast; the avatar is the symbol, never the full lockup.
  • The 5-second test — a stranger should be able to draw the mark from memory after seeing it once.
  • One square icon everywhere — the same 800×800 asset serves every platform.
  • 2–3 colours, negative space, symbol built into the form — the freshest medical marks integrate, never decorate.
