# Disabled staged dashboard — do not upload

`dashboard.html` is an experimental dashboard generated by `build-staged-dashboard.py` from GitHub main commit `2d8d0d0`. It is **not deployed**, defaults to a fail-closed configuration, and is not ready for customers. It imports the three local adapters in this directory and `secure-config.mjs`. The actual live dashboard remains unchanged.

The candidate connects the dashboard to staged authenticated question, checkout, access and migration-preflight functions; hydrates authorized blocks and migrated history; and presents an unchecked auto-renew checkbox. The nonrenewing checkout requires separately configured one-time Paddle prices; existing recurring IDs are retained for explicit opt-in. All identifiers and feature flags are placeholders. No secret belongs in the browser config.
