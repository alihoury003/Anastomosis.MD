# Disabled staged dashboard — do not upload

`dashboard.html` is an experimental dashboard generated by `build-staged-dashboard.py` from GitHub main commit `2d8d0d0`. It is **not deployed**, defaults to a fail-closed configuration, and is not ready for customers. It imports the three local adapters in this directory and `secure-config.mjs`. The actual live dashboard remains unchanged.

The candidate connects the dashboard to staged authenticated question, checkout, access and migration-preflight functions; hydrates each authorized question on first display and restores migrated history; and presents an unchecked auto-renew checkbox. The nonrenewing checkout requires separately configured one-time Paddle prices; existing recurring IDs are retained for explicit opt-in. All identifiers and feature flags are placeholders. No secret belongs in the browser config.

Before release: finish and approve migration and the new delivery-based quota policy, implement operations/reconciliation, provision the private schema, verify the actual environment, add one-time prices only with approval, check promo eligibility, run real sandbox and importer tests, compare current main to the pinned base, and validate the protected exam UI. Never upload this candidate or change live default payment settings before those checks. See `../payment-backend/README.md` for specific limitations.

`refund-reviews.html` is a separate disabled candidate admin page with a private access-decision workflow and read-only catalog check. It does not issue, cancel or reverse refunds and is not linked from the live site. The proposed default allows access while partial refunds/credits await review, but restricts the related paid source for full refunds/credits or chargebacks until reviewed. This policy, the required private Appwrite functions/tables, six Paddle prices and discount compatibility have not been approved or tested in real accounts. Do not upload it.
